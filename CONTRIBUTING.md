# Contributing and reporting problems

This preview welcomes reproducible error reports and source-interpretation
questions. Open a GitHub issue and include:

- dataset version;
- table and stable identifier (`source_id`, `study_id`, or `network_id`);
- the source row, column, page, or method passage supporting the concern;
- observed and expected behavior; and
- a minimal code example when the problem is computational.

Do not submit copyrighted source files, credentials, sensitive locality data,
or unnecessary personal information in an issue. Link to the upstream record
instead.

Scientific interpretation changes require comparison with the original data
and methods, a written rationale, a rebuild, and renewed validation. Parser or
schema changes should include a regression test. Human-review outcomes belong
in the controlled review ledger and must identify the reviewer and date.

The preview is not accepting new sources merely to increase the network count.
Candidate additions must meet the documented ecological boundary, evidence,
methods, provenance, and reuse requirements.
