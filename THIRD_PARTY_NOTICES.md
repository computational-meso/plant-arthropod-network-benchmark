# Upstream data and attribution

This repository distributes harmonized derived tables, not copies of the
upstream raw archives. Every source-derived component is identified in the
`sources`, `derived_products`, and `file_manifest` tables included with the
release.

Nine currently ingested Dryad sources report CC0 terms. The Shinohara et al.
source is distributed under CC BY 4.0 and must be attributed as specified in
the source tables. Two Maunsell supporting documents are recorded as
`retrieval_manifest_only_source_terms`; those files are not distributed here
and the candidate contributes no released network objects.

CC0 for the synthesis creators' contributions does not erase source citations,
provenance, or upstream obligations. Cite the original studies when using their
source-derived components.
